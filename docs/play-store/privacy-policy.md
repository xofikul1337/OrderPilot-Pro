# Privacy Policy

Effective date: June 8, 2026

OrderPilot Pro is a WooCommerce order management app developed by Sukunaat / Shofiul Islam. This Privacy Policy explains how OrderPilot Pro handles data when merchants and staff connect the mobile app to a WooCommerce store using the OrderPilot Pro WordPress plugin.

## Data We Process

OrderPilot Pro may access or process the following data after a store is connected:

- Store connection information, including Store ID, staff name, device identifier generated by the app, and connection token.
- WooCommerce order information, including order number, customer name, phone number, email address, billing/shipping address, ordered products, order total, payment method title, order status, custom checkout fields, and staff notes.
- Staff activity information, including seen/unseen state, assigned staff name, status updates, note updates, claim/release activity, and activity timestamps.
- Notification data needed to deliver new order alerts through OneSignal.

## How Data Is Used

Data is used to:

- Connect staff devices to a merchant's WooCommerce store.
- Display WooCommerce orders in the app.
- Send new order notifications.
- Track whether staff have seen or managed an order.
- Let staff update order status, notes, assignment, and activity history.
- Improve security by detecting proxy or VPN usage before sensitive API calls.

## Data Storage

Order data, seen state, staff assignment, and activity history are stored in the merchant's own WordPress/WooCommerce database. OrderPilot Pro's Cloudflare Worker is used as a license, notification, and mobile API proxy. It does not store WooCommerce order history in Cloudflare D1.

The app stores limited local data on the device, such as connection token, Store ID, staff name, generated device ID, and cached order notification history.

## Data Sharing

OrderPilot Pro may share limited data with:

- The merchant's connected WordPress/WooCommerce website.
- OneSignal, for push notification delivery.
- Cloudflare Worker, for license validation, store routing, and push/API proxying.

OrderPilot Pro does not sell user data.

## Security

OrderPilot Pro uses HTTPS for network communication, app-side proxy/VPN detection, app connection tokens, and WordPress REST API authentication. Merchants are responsible for keeping their WordPress site, WooCommerce, and hosting environment secure.

## Data Retention and Deletion

WooCommerce order data is retained according to the merchant's WordPress/WooCommerce retention settings. Staff/device connection records and activity records are stored in the merchant's WordPress database until deleted by the merchant or plugin/app actions.

Users may disconnect a device from the app settings. Merchants may remove plugin data from their WordPress database according to their own data retention and deletion process.

To request deletion or support, contact support@sukunaat.com.

## Children

OrderPilot Pro is intended for business use by store owners and staff. It is not directed to children.

This Privacy Policy may be updated when product features, data handling, or legal requirements change.
