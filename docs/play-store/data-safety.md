# Google Play Data Safety Draft

Use this as the starting point for Play Console > App content > Data safety.

## Data Collection

The app collects or processes user/order data only after the merchant or staff connects a WooCommerce store.

Data types:

- Personal info: customer name, email address, phone number, address.
- App activity: order views, seen/unseen state, staff actions, claim/release activity.
- App info and performance: limited device/app state needed for push notifications and connection.
- Device or other IDs: generated app device ID and OneSignal push subscription ID.

## Data Sharing

Data may be shared with:

- Merchant's WordPress/WooCommerce website.
- OneSignal for push notifications.
- Cloudflare Worker for routing/API proxy and notification delivery.

No data is sold.

## Security Practices

- Data is encrypted in transit using HTTPS.
- App uses connection tokens.
- App detects proxy/VPN use before sensitive API calls.
- Merchant order data is stored in the merchant's own WordPress database.

## Data Deletion

Users can disconnect their device in app settings. Merchants can delete order/staff data from their WordPress/WooCommerce system or request help at support@sukunaat.com.

## Account Creation

The app does not create a public consumer account. Staff connect to an existing merchant store using a Store ID generated by the WordPress plugin.
