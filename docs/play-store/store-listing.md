# Google Play Store Listing Draft

## App Name

OrderPilot Pro

## Short Description

WooCommerce order alerts and staff order management from your phone.

## Full Description

OrderPilot Pro helps WooCommerce store owners and staff manage orders faster from Android.

Connect your store with the OrderPilot Pro WordPress plugin, receive new order notifications, view order details, track seen/unseen status, search orders, filter by status, update order status, save notes, assign orders to staff, and review activity history.

Key features:

- New WooCommerce order notifications
- Store ID based app connection
- Staff seen/unseen tracking
- Order search and status filters
- Native order detail screen
- Confirm, pending, on-hold, sent-to-courier, cancel order actions
- Staff assignment and activity timeline
- Custom checkout field display
- WordPress-local order data storage
- Proxy/VPN detection for safer API access

OrderPilot Pro is built for WooCommerce merchants, ecommerce teams, and agencies that need faster order handling without opening the WordPress dashboard all day.
