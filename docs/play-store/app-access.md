# Play Console App Access Instructions

If Google Play review needs to access restricted features, provide this in Play Console > App content > App access.

## Access Type

Some app features require a connected WooCommerce store.

## Reviewer Steps

1. Open OrderPilot Pro.
2. Tap Settings.
3. Enter Staff Name: `Google Reviewer`
4. Enter Store ID: `889123`
5. Tap Connect.
6. Return to Home to view orders, filters, search, order details, assignment, and activity timeline.

If the demo store is unavailable during review, contact support@sukunaat.com.

## Notes

The app is for WooCommerce merchants/staff. It is normal for the Home screen to ask for Store ID before showing order management features.
